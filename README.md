# WebLoom

WebLoom 是一个运行在浏览器中的轻量级 Agent 插件，目标是在尽量精简的架构下，把用户当前打开的网页内容转化为可直接用于问答的实时上下文，让浏览器本身成为一个可交互的本地智能工作台。

第一版以 Chrome Manifest V3 插件形态实现，主要通过侧边栏提供聊天界面，在用户提问时自动采集当前网页或已打开标签页的可读内容，并将问题、历史会话、网页上下文以及可用工具描述一起组织给模型。模型既可以直接回答，也可以在有必要时自主决定调用 MCP 工具；真正执行工具前，插件会向用户展示工具来源、名称和参数，保证调用过程可控、可解释。

整个产品强调“尽量都在浏览器内完成”：

- 不依赖额外后端服务
- 本地保存会话与配置
- 自动采集网页正文作为上下文
- 支持基于当前页面或多个已打开页面进行问答
- 支持通过 OpenAI 兼容接口接入 LLM
- 支持通过 HTTP 接入 MCP 服务，并在需要时执行工具调用

因此，WebLoom 更适合这样的使用场景：当你正在阅读网页、查资料、对比多个标签页内容，或者希望让模型基于当前浏览器环境回答问题时，无需手动复制粘贴页面内容，就可以直接在侧边栏中发起对话。

## 构建方式

在项目根目录执行以下命令安装依赖并生成正式构建产物：

```bash
npm install
npm run build
```

构建完成后，正式版本输出在 `.output/chrome-mv3` 目录，可直接在 Chrome 的 `chrome://extensions` 中通过“加载已解压的扩展程序”进行加载。
